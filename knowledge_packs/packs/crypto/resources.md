# Crypto Resources

Curated references this pack was compiled from. Used by the specialist to look
up a specific scheme, and by `refresh.py` as scrape targets.

## Primary references
- HackTricks source — Cryptography (markdown, non-gated): https://github.com/HackTricks-wiki/hacktricks/tree/master/src/crypto
- HackTricks source — Stego: https://github.com/HackTricks-wiki/hacktricks/tree/master/src/stego
- CryptoHack (learn-by-doing, excellent attack explanations): https://cryptohack.org/
- Cryptopals Crypto Challenges (the canonical practical set): https://cryptopals.com/

## Attack-specific
- RsaCtfTool (attack catalog in README): https://github.com/RsaCtfTool/RsaCtfTool
- RSA attack notes: https://github.com/ashutosh1206/Crypton
- Coppersmith / lattice (Sage recipes): https://github.com/defund/coppersmith
- Padding oracle explainer: https://robertheaton.com/2013/07/29/padding-oracle-attack/
- Hash length extension: https://github.com/iagox86/hash_extender
- MT19937 / Python random cracking: https://github.com/tna0y/Python-random-module-cracker

## Lookup / compute
- FactorDB (known factorizations): http://factordb.com/
- dcode.fr (classical ciphers, auto-solvers): https://www.dcode.fr/
- quipqiup (substitution solver): https://quipqiup.com/
- CyberChef (encoding chains, Magic): https://gchq.github.io/CyberChef/

## Writeup archives (search the exact scheme name)
- CTFtime writeups: https://ctftime.org/writeups
- 0x00sec / Google "<scheme name> CTF writeup"
